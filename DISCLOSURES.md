# Disclosures

SahAI is an independent hackathon prototype and is not affiliated with any government body.

Built with Next.js-compatible Vinext, React, Tailwind CSS, shadcn/ui, Lucide icons, Express, Zod, Supabase JS, React PDF, Resend, OpenAI Realtime, and Vitest. Fonts use Geist and system Devanagari fallbacks. Built with Codex. No government code, logos, emblems, or private APIs are used. Government, police, bank, Aadhaar, SMS, and platform actions shown in the demo are simulated.
